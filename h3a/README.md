# H3a – Perintä (Chef ja ItalianChef)

Kantaluokka `Chef` ja siitä periytyvä `ItalianChef` UML-kaavion mukaan.
Konstruktorit ja destruktorit tulostavat debug-tietoa, joten tulosteesta näkee
olioiden luonti- ja tuhoamisjärjestyksen.
